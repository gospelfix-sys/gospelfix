# GOSPELFIX Mall — 프로젝트 정체성

## 핵심 슬로건

> **"AI가 붙은 업종별 홈페이지를, 오늘 사면 내일 바로 운영할 수 있게 판다."**

## 카피 (고객 언어)

> **"당신의 업종에 맞는 AI 홈페이지, 오늘 구매하면 내일 바로 오픈."**

- 슬로건은 내부 정체성 기준, 카피는 실제 UI/마케팅 문구로 사용

## 무엇을 파는가

브랜드 템플릿(카페24, 워드프레스 등) + AI 기능 탑재 + 배포까지 포함된 **완성형 상품**을 판매하는 마켓플레이스.

- 상품 단위: 업종별 완성형 AI 홈페이지 패키지 (미용실, 카페, 병원, 학원 등)
- 구매자는 코드 + AI 기능 + 배포 가이드를 한 번에 받아 **즉시 영업 투입** 가능
- 단순 디자인 템플릿이 아닌 **AI 기능이 내장된 올인원 패키지** 가 본질

## 기존 템플릿 마켓과의 차별점

| 기존 마켓 (카페24, 워드프레스) | gospelfix-mall |
|-------------------------------|---------------|
| 디자인 템플릿만 제공 | AI 기능 내장 |
| 구매 후 직접 설정 필요 | 배포까지 포함 |
| 기술 지식 필요 | 비기술자도 다음날 바로 운영 가능 |

## 기획/개발 판단 기준

모든 기능 설계 및 UI 결정 시 아래 질문들을 기준으로 판단한다.

### 핵심 질문 (반드시 통과해야 함)
1. **"이 기능이 구매자가 내일 바로 운영할 수 있게 돕는가?"**
2. **"비개발자(미용실 사장, 카페 사장)도 이 UI를 보고 바로 이해할 수 있는가?"**
3. **"이 상품을 사면 무엇을 받는지, 3초 안에 파악되는가?"**

### 보조 질문 (방향 검토 시 참고)
4. **"이 기능이 없으면 구매자가 내일 오픈하지 못하는가?"** — No이면 우선순위 낮춤
5. **"이 UI가 '구매 → 설치 → 오픈' 흐름을 단축시키는가?"** — 복잡도 추가 시 반드시 검토
6. **"업종별 특성이 상품 카드/상세 페이지에 충분히 반영되어 있는가?"** — 미용실과 카페는 다르게 보여야 함
7. **"AI 기능이 실제 영업에 도움이 된다고 구매자가 느끼는가?"** — 기술 자랑이 아닌 실용성 기준
