# 가스펄픽스 — 프로젝트 정체성

## 핵심 슬로건

> **"브랜딩에 들어가는 모든 디자인 소재를, 한 곳에서."**

## 카피 (고객 언어)

> **"당신만의 브랜드를 구매하세요"**

- 슬로건은 내부 정체성 기준, 카피는 실제 UI/마케팅 문구로 사용
- 홈(`/`) 히어로: 배지 "브랜딩 디자인 소재 마켓" / 타이틀 "당신만의 브랜드를 구매하세요" /
  CTA "디자인 소재 둘러보기" (2026-10-27 확정)

## 무엇을 파는가

브랜딩에 들어가는 **모든 디자인 소재**를 판매하는 마켓플레이스.

- CI 로고
- 목업
- 홈페이지 템플릿
- 대시보드 템플릿
- 이커머스 템플릿
- 광고 소재 (PSD, AI 파일 등)
- 구매자는 파일을 내려받아 자기 브랜드에 바로 적용한다
- 이전 정체성("AI가 붙은 업종별 홈페이지를 오늘 사면 내일 오픈")은 폐기했다. 웹 템플릿은 여러
  소재 카테고리 중 하나로 격하됐다.

## 기획/개발 판단 기준

모든 기능 설계 및 UI 결정 시 아래 질문들을 기준으로 판단한다.

1. **"이 소재가 무엇이고 어떤 파일 형식으로 받는지 3초 안에 파악되는가?"**
2. **"카테고리(로고·목업·템플릿·광고 소재)를 가로질러 탐색하기 쉬운가?"**
3. **"구매 후 바로 내려받아 브랜드에 적용할 수 있는가?"**
4. **"비디자이너도 이 UI를 보고 필요한 소재를 고를 수 있는가?"**
