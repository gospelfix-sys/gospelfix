## 한 줄 정의

> "당신의 업종에 맞는 AI 홈페이지, 오늘 구매하면 내일 바로 오픈."

## 플랫폼 구조 (2026-08-14 갱신 — 양면 마켓플레이스로 확장)

```
구매자 (소상공인)   →  AI 홈페이지·템플릿 구매
판매자 (AI 빌더)    →  템플릿·컴포넌트·프롬프트 파일 등록 및 판매
운영자 (GospelFix)  →  검수·승인·정산·플랫폼 운영, 수수료 30%
```

> 소상공인이 돈을 낸다. AI 빌더가 상품을 만든다. GospelFix가 연결하고
> 수수료를 받는다. 판매자 수익 70% / GospelFix 수수료 30%.

**단, 판매자(외부 AI 빌더) 입점은 Phase 3(3~6개월 후, 지인 3명 베타)로 명시된
미래 계획이다. 지금은 GospelFix 자체 상품 판매(Phase 1)에 집중하는 단계이며,
판매자 마켓플레이스 관련 UI/문구를 지금 페이지에 노출하지 않기로 확정했다
(과장광고 방지). 상세 일정은 [`ROADMAP.md`](../../ROADMAP.md) 참고.**

## 타겟

### 구매자 — 소상공인
- 업종: 뷰티·헬스·필라테스 / 이사·청소 / 카페·요식업 / 병원·한의원·치과 /
  학원·교육 (제작 우선순위도 이 순서)
- 규모: 직원 1~5명, "아임웹도 어려운" 기술 수준
- 핵심 페인 포인트: 밤에 카카오톡으로 예약 문의가 오면 아침에 일어나서 답장 →
  그 사이 고객은 다른 데로 간다. GospelFix가 파는 건 홈페이지가 아니라 "자는
  동안에도 운영되는 가게".

### 판매자 — AI 빌더 (Phase 3부터 실제 온보딩)
- 대상: 개발자·디자이너·1인 창업자·프리랜서
- 니즈: "내가 만든 걸 팔고 싶은데 트래픽이 없다"
- 혜택: GospelFix 트래픽으로 판매 가능, 별도 마케팅 불필요
- 상품: 템플릿·컴포넌트·프롬프트 파일·소스코드

## 경쟁 포지셔닝 & 차별화

아임웹·카페24(플랫폼, 혼자 만들어야 함) / 디자인키트(HTML만 던져줌, AI 없음) /
일반 에이전시(비쌈·느림·AI 없음) / 크몽(용역 중계, 파일 판매 아님) 대비,
GospelFix는 **AI 기능 탑재 템플릿 + 배포까지 + 마켓플레이스**가 차별점.

- AI 챗봇 탑재 → 24시간 고객 응대 자동화
- 업종별 FAQ 자동 답변
- 견적 문의 자동화 (평수·옵션 입력 → 즉시 산출, 이사·청소 업종 특화)
- 배포까지 포함 (소상공인이 할 게 없음)

## 상품 구조 (가격은 웹페이지 카피에 직접 노출하지 않기로 결정 — mall 상세/결제
단계에서만 표시)

- 템플릿: FREE(컴포넌트 단독, 회원가입 유인) / 기본형 98,000원(소스+배포가이드) /
  표준형 198,000원(소스+AI챗봇+배포) / 프리미엄 298,000원~(소스+AI챗봇+커스터마이징+배포)
- 유지보수 월정액(**핵심 MRR**): 기본 29,000원/월, AI 기능 포함 49,000원/월 —
  면도기(템플릿)-면도날(유지보수) 모델. 한 번 팔고 끝나는 구조가 아니라 MRR을
  쌓는 구조가 핵심.
- 판매자 수익 구조(Phase 3): 판매자 70% / GospelFix 수수료 30%

구매 → 유지보수 계약. 카카오 챗봇 연동/AI 자동응답 세팅/월간 리포트가 "떼어내기

## Why

기존 `/`·`/about`·`/growth` 페이지는 "에이전시형 B2B(맞춤 제작) + STORE
B2C(템플릿 판매)"라는 범용 포지셔닝이었으나, 2026-08-14 대화에서
`gospelfix-business-model.md`를 근거로 "업종별 AI 홈페이지 + AI 챗봇 자동응대 +
유지보수 MRR" 방향으로 카피를 전면 피벗했다(코드/데이터 구조는 유지, 설명
문구만 교체). 같은 날 후속 대화에서 원본 문서가 **양면 마켓플레이스**(판매자
=AI 빌더, 수수료 30%) 모델로 확장 갱신됐음을 확인했고, 이 마켓플레이스 부분은
Phase 3(3~6개월 후) 계획이라 지금 페이지 카피에는 반영하지 않기로 하고
`ROADMAP.md`에 계획만 문서화했다.

## How to apply

향후 새 기능·페이지·상품 제안이 들어오면 다음 기준으로 점검하고, 벗어나면
**"비즈니스 방향성과 맞지 않는 기능"이라고 과감하게 지적할 것**:

1. 업종별(뷰티/이사/카페/병원/학원) AI 홈페이지에 기여하는가
2. AI 챗봇 24시간 자동응대와 관련 있는가
3. 견적/FAQ 자동화처럼 업종 특화 자동화인가
4. "구매 즉시 배포"라는 속도 약속을 지키는가
5. 유지보수 월정액(MRR)으로 이어지는 구조인가
6. **(신규)** 이 기능이 Phase 1(자체 상품/AI챗봇/콘텐츠) 범위인가, 아니면
   Phase 3(판매자 마켓플레이스) 범위인가? Phase 3 성격의 요청(판매자 등록,
   정산, 수수료 등)이 지금 들어오면 "아직 이르다, `ROADMAP.md` Phase 3 참고"라고
   알릴 것. Phase 1과도 Phase 3과도 무관한 기능은 기존과 같이 방향성 불일치로
   지적할 것.

**해소된 불일치**: `/`·`/about`·`/growth` 마케팅 카피(ticker·히어로 배너·CTA
배너 포함)는 이미 이 방향으로 전면 반영·검증(lint+build) 완료됐다. 실 상품
카테고리(`landing`/`dashboard`/`ecommerce`/`corporate`)도 문서의 카테고리
표와 일치함을 확인했다. 헤더 내비게이션(GOSPELFIX/STORE 탭) 구조는 아직
스코프 밖.

원본 참고 문서: `/Users/mac/Downloads/gospelfix-business-model.md` (저장소 밖
파일이라 이동/삭제될 수 있고, 실제로 이번에 191줄→266줄로 갱신된 이력이 있음 —
위 내용이 최신 버전의 대체본. 다음에도 이 파일을 다시 참고하라는 요청이 오면

## 2026-08-21 갱신 — "판매자" 설명 문구를 "AI 빌더"에서 "다양한 포지션의 전문
크리에이터"로 확장 (카피 문구만, 상품 카테고리·Phase 3 계획은 불변)

`/about`의 모다(MODA)·B2C 카드와 `/growth`의 브랜드 소개 바·"Why 모다"
섹션에서 판매자를 가리키던 "AI 빌더"라는 표현을 "영상·그래픽·브랜딩·UI/UX·
일러스트레이션·AI 등 다양한 포지션의 전문 크리에이터"로 넓혔다. 참고 사이트로
notefolio.net(크리에이터 포트폴리오 전시 + 클라이언트 매칭 플랫폼)을 제시받았다.

**중요**: 이건 카피(브랜드 스토리)만 넓힌 것이고, 실제 상품 카테고리
(`types/product.types.ts`의 `PRODUCT_CATEGORIES` = landing/dashboard/
ecommerce/corporate, 여전히 웹 템플릿뿐)와 Phase 3 판매자 마켓플레이스
기능(마이페이지·정산·수수료 등, 위 "판매자 시스템" 섹션 참고)은 전혀 손대지
않았다. "다양한 크리에이터가 영상·사진·일러스트까지 판다"고 실제로 확장하는
건 아직 결정된 바 없다 — 만약 향후 그런 요청이 오면 이건 Phase 3보다도 더 큰
카탈로그 확장(신규 상품 유형·카테고리 스키마 변경)이므로 반드시 사용자에게
먼저 확인할 것.

## How to apply (추가)

7. "모다 판매자가 누구인지" 설명하는 카피를 새로 쓰거나 검토할 때는 "AI 빌더"
   같은 좁은 표현 대신 "다양한 포지션의 전문 크리에이터"(영상·그래픽·브랜딩·
   UI/UX·일러스트레이션·AI 등)로 통일한다. 단, 실제 판매 상품이 웹 템플릿
   외로 확장됐다고 암시하는 문구(예: "포토그래피·영상 편집 서비스 구매 가능")는
   카탈로그가 실제로 그렇게 바뀌기 전까지 넣지 않는다 — 과장 광고 방지 원칙은
   여전히 유효하다.
