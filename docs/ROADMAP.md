# gospelfix ROADMAP

> 브랜딩 디자인 소재 마켓 사용자 앱 — `gospelfix.cms.api`를 BFF로 호출하는 순수 프론트엔드 레포
> 최종 갱신: 2026-10-27 (제품 범위와 현재 상태는 [`PRD.md`](./PRD.md) 참고)

---

## 타임라인

| Phase                    | 상태 | 요약                                                                    |
| ------------------------ | ---- | ----------------------------------------------------------------------- |
| 1 — 기반 인프라          | 완료 | Next.js, Recoil, cms.api BFF 연동, Tailwind v3 + shadcn(base-nova)      |
| 2 — 마켓 핵심 기능       | 완료 | 소재 마켓(`/`), 상세, 구매, 계좌이체, 마이페이지, 블로그, 리뷰          |
| 3 — 회원가입/로그인 개선 | 완료 | 팝업 모달 전환, 최소 수집 가입(이메일+비밀번호+약관), 이메일 인증 코드 |
| 4 — 구매 경험 확장       | 진행 | 장바구니·쿠폰·추천인·카카오 로그인 완료, 결제 자동화·환불은 남음        |
| 5 — 콘텐츠·정체성 정리   | 예정 | 준비 중 페이지 채우기, 메타데이터·브랜드명 정리                         |

---

## Phase 1~3 — 완료

- [x] Next.js 14 App Router, Recoil, cms.api BFF 구조(`cmsApiFetch()` 서버 전용, 브라우저는 이 앱의 `/api/*`만 호출)
- [x] 소재 마켓 홈(`/`), 상세(`/detail/[slug]`, 모달 + 풀 페이지), 블로그(`/blog`), 리뷰(구매 검증 후 작성)
- [x] 구매 흐름 — 주문 생성 → 무료는 즉시 완료 / 유료는 계좌이체 안내 → 입금 신고 → 관리자 수동 확인
- [x] 마이페이지 — 주문 내역, 내 작품, 내 리뷰, 계정 설정(비밀번호 변경·판매자 전환 신청·탈퇴)
- [x] `/login`, `/register`를 별도 페이지에서 팝업 모달로 전환
- [x] 가입 시 이름·휴대폰을 받지 않는 최소 수집 정책(필요한 순간에 수집)
- [x] 문의하기(견적) 기능 전체 제거(2026-10-27)

---

## Phase 4: 구매 경험 확장 — 진행 중

- [x] 장바구니와 일괄 결제(`orders/create-batch`)
- [x] 쿠폰, 추천인 코드·배너
- [x] 카카오 로그인(scope `account_email`만)
- [x] 공급원가(`supply_price`)와 할인가 표시
- [ ] 결제 자동화 — 현재 계좌이체 + 관리자 수동 확인. 가상계좌 등 자동 입금 확인 도입 검토. 난이도: 상
- [ ] 환불/취소 플로우 — 규정 문구만 있고 화면·API가 없음. 난이도: 중

---

## Phase 5: 콘텐츠·정체성 정리 — 예정

- [ ] `/free-resources`, `/creator`, `/guide` 자리표시 페이지 채우기(신설 시 `layerNav.ts`의 `LAYER_NAV_ITEMS` 등록)
- [ ] `layout.tsx` 기본 title/OG 문구를 현재 정체성(브랜딩 디자인 소재 마켓)으로 교체
- [ ] 페이지별 브랜드명 정리 — `/introduce`, `/creator`, `/free-resources`, `/upload`의 "모다(MODA)", `/about`·`/layer`의 AI 에이전시 문구
- [ ] 소재 카테고리 재정의(로고·목업·홈페이지·대시보드·이커머스 템플릿·광고 소재)와 파일 형식(PSD/AI) 표기 — cms.api 협의 필요
- [ ] 마이페이지 확장 후보: 주문 상세/영수증, 리뷰 수정·삭제

## 리스크 및 미결정 사항

| 항목                                | 영향도 | 비고                                                             |
| ----------------------------------- | ------ | ---------------------------------------------------------------- |
| 결제 완전 수동(PG 미연동)           | 높음   | 주문량 증가 시 관리자 확인 지연이 곧 병목                        |
| 환불/취소 흐름 없음                 | 높음   | 규정 문구만 존재                                                 |
| 환경변수는 Vercel에 별도 등록       | 높음   | 신규 env 추가 시 Vercel 대시보드 등록 + 재배포 필요(반복 발생)   |
| 사이트 메타데이터·브랜드명 불일치   | 중간   | Phase 5 참고                                                     |
| 이미지 최적화 우회                  | 낮음   | `images.unoptimized: true`는 Vercel 402 임시 우회, 원복 여부 대기 |
