# gospelfix ROADMAP

> 템플릿 마켓플레이스 구매자용 사이트 — `gospelfix.cms.api`를 BFF로 호출하는 순수 프론트엔드 레포
> 최종 갱신: 2026-07-27

---

## 프로젝트 개요

**비전**: 방문자가 템플릿을 발견하고, 회원가입하고, 구매하고, 다운로드하기까지 이 사이트 하나로 완결

**성공 지표**

- 회원가입 완료율, 구매 전환율, 계좌이체 확인까지의 평균 소요 시간
- `gospelfix.cms.api`에서 콘텐츠(상품/포트폴리오/블로그)를 추가하면 코드 변경 없이 이 사이트에 즉시 반영

**전체 타임라인**

| Phase                             | 상태 | 요약                                                    |
| --------------------------------- | ---- | ------------------------------------------------------- |
| Phase 1 — 기반 인프라             | 완료 | Next.js, Recoil, cms.api BFF 연동 구조                  |
| Phase 2 — 마켓 핵심 기능          | 완료 | 마켓/상세/구매/계좌이체/마이페이지/견적/블로그/리뷰     |
| Phase 3 — 회원가입/로그인 UX 개선 | 완료 | 팝업 모달 전환, 가입 최소 수집(이메일+비밀번호+약관)으로 전환 |
| Phase 4 — 구매 경험 확장          | 예정 | 장바구니, 결제 자동화, 소셜 로그인                      |
| Phase 5 — 마이페이지 확장         | 예정 | 프로필 수정, 주문 상세, 리뷰 관리                       |

---

## Phase 1: 기반 인프라 — 완료

- [x] Next.js 14 App Router 세팅
- [x] Recoil 상태 관리 (`authAtom`, `userAtom`, `uiAtom`)
- [x] `gospelfix.cms.api` BFF 연동 구조 확립 (`cmsApiFetch()` 서버 전용, 브라우저는 이 앱의 `/api/*`만 호출)
- [x] Tailwind v3 + shadcn(base-nova) 디자인 시스템, 브랜드 컬러 토큰

---

## Phase 2: 마켓 핵심 기능 — 완료

- [x] 홈(`/`) — 히어로, 포트폴리오 스와이퍼, 통계, CTA
- [x] 마켓(`/mall`) — 카테고리 필터 템플릿 그리드
- [x] 상품 상세(`/detail/[slug]`) — 디바이스 프리뷰, 구매 옵션, 리뷰
- [x] 구매 흐름 — 주문 생성 → 무료 상품 즉시완료 / 유료 상품 계좌이체 안내(QR+계좌번호) → 입금 알림 → 관리자 수동 확인 대기
- [x] 마이페이지(`/dashboard`) — 구매 내역 + 다운로드
- [x] ~~커스텀 견적 마법사(`/quote`)~~ — 제거됨(2026-10-27)
- [x] 블로그(`/blog`, `/blog/[slug]`) — Lexical HTML 렌더링
- [x] 리뷰 — 구매 검증 후 작성, 공개 조회
- [x] 이용약관/개인정보처리방침 정적 페이지

---

## Phase 3: 회원가입/로그인 UX 개선 — 완료 (카카오 전환만 진행 중)

- [x] `/login`, `/register` 별도 페이지 → **팝업 모달**로 전환 (기존 링크는 리다이렉트 셔임으로 호환 유지)
- [x] 회원가입에 휴대폰 인증 추가 (발송/확인/토큰 발급, 서버 재검증) → 이후 최소 수집 정책으로 가입 폼에서 제거(이메일+비밀번호+약관 3종)
- [x] 비밀번호 확인 필드 추가
- [x] CSS 변수 + Tailwind opacity 모디파이어 조합이 깨지는 버그 수정 (`ring-black/10` 등 리터럴 rgba로 교체) — 팝업 모달 테두리에 의도치 않은 파란색이 뜨던 문제
- [x] `Button` 컴포넌트를 `React.forwardRef`로 전환 (`DialogClose` render prop 패턴의 ref 경고 해결)
- [ ] ~~휴대폰 인증 발송 채널을 SMS → 카카오 알림톡으로 전환~~ (가입 시 휴대폰 인증 제거로 가입 목적에서는 불필요. 다른 용도로 재정의 시 부활) — `gospelfix.cms.api` 쪽 작업, 템플릿 심사 승인 대기 중 (진행 상태: `gospelfix.cms.api/.claude/memory/kakao-alimtalk-migration.md`)

### 완료 기준

- 어느 페이지에서든 회원가입/로그인 팝업을 띄울 수 있고, 닫았다 열어도 상태가 깨지지 않음
- 가입 폼은 이메일·비밀번호·필수 약관만 받음(휴대폰 인증 제거, cms.api 쪽 휴대폰 필수 여부는 별도 확인 필요)

## 리스크 및 미결정 사항

| 항목                                      | 영향도 | 상태      | 비고                                                                |
| ----------------------------------------- | ------ | --------- | ------------------------------------------------------------------- |
| 장바구니 미구현                           | 높음   | 인지됨    | 단건 구매만 가능, 객단가 확장의 병목                                |
| 결제 완전 수동(PG 미연동)                 | 높음   | 인지됨    | 주문량 증가 시 관리자 확인 지연이 곧 병목                           |
| 소셜 로그인 하드 스텁                     | 중간   | 인지됨    | UI는 있는데 클릭 시 항상 에러 — 노출 여부 재검토 필요               |
| `PurchaseOptionsPanel` 공급원가 임시 목업 | 중간   | 인지됨    | `cms.api`에 `supply_price` 필드 추가 전까지 판매가의 2배로 하드코딩 |
| `@base-ui/react` 마이그레이션 미완료      | 낮음   | 인지됨    | 일부 컴포넌트가 여전히 `@radix-ui`(`Label`, `Slot`) 사용            |
| 마이페이지 기능 최소                      | 중간   | 인지됨    | 프로필/비밀번호/주문상세/리뷰관리 없음                              |
| 카카오 알림톡 템플릿 미승인               | 낮음   | 보류      | `gospelfix.cms.api` 쪽 작업, 승인 전까지 SMS 발송 유지              |
| `.env.local`은 Vercel에 반영 안 됨        | 높음   | 반복 발생 | 신규 env 변수 추가 시 항상 Vercel 대시보드에도 등록 + 재배포 필요   |
